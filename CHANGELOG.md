# Changelog

All notable changes to DropShelf are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and releases use semantic versioning.

## [1.0.0] - 2026-07-15

### Added

- Screen-edge shelf with animated expand and collapse behavior.
- Native file and folder drag-in and drag-out.
- Text, link, image, file, and folder item types.
- Local image previews and native file icons.
- Search, content filters, selection, pinning, and item context menus.
- Automatic expiry for unpinned items.
- Explicit and optional automatic clipboard capture.
- System tray, global keyboard shortcut, and launch-at-login support.
- Left- and right-edge positioning.
- Automatic light and dark appearance.
- First-run experience, settings panel, empty states, and accessible keyboard interactions.
- Windows installer and portable packaging configuration.
- Cross-platform CI and release workflows.
