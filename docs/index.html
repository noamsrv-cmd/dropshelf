Privacy is the architecture

Your shelf is
not our business.

DropShelf has no backend, analytics, tracking pixel, or account system. It stores a small readable state file on your computer and references the files you explicitly add.

Read the security model →
  • ✓
    Local storage onlyNothing is uploaded or synchronized.
  • ✓
    Clipboard is opt-inAutomatic monitoring starts disabled.
  • ✓
    Originals stay untouchedRemoving a shelf item only removes its reference.
